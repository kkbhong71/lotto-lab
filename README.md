> 통계 교육 자료입니다.

## 무엇이 들어 있나

| 파일 | 설명 |
|---|---|
| `index.html` | **웹앱 (v2.0)** — 드래그 앤 드롭 단일 HTML. 브라우저에서 바로 실행 |
| `python/lotto_integrated_v1_1.py` | **Python 레퍼런스 (v1.1)** — Google Colab용. 웹앱 엔진의 원본 구현 |
| `data/new_1235.csv` | 예시 데이터 — 1~1235회차 당첨번호 (공개 정보) |

두 구현은 같은 데이터에서 결정적 계산부(점수 6종·클러스터·필터 12종)가
**최대 오차 1e-16 수준으로 일치**하도록 교차 검증되었습니다.

## 주요 기능

**분석 엔진** — 빈도·최근성·간격·동반출현·모멘텀·구간 6개 지표의 가중 합성 점수,
간이 클러스터링, 12종 통계 필터, 클러스터 쿼터 기반 커버리지 최적화로 5세트를 생성합니다.

**Walk-forward 백테스트 + 랜덤 대조군** — 각 검증 회차마다 그 이전 데이터만으로
엔진을 재구성하고(미래 데이터 누수 없음), 같은 회차에 순수 랜덤 100세트를 함께 던져
공정하게 비교합니다. 판정은 임의 기준이 아니라 **부트스트랩 랜덤 귀무분포의 95% 구간**으로
내립니다.

**사전 예측 추적** — 생성된 예측은 자동으로 기록되고(같은 회차 재기록 방지),
다음 회차 파일을 놓으면 자동 채점됩니다. 백테스트(과거 시뮬레이션)와 달리
"그 시점에 실제로 예측했다"는 사전 등록 증거가 누적되며, 목표 표본(50회차)에
도달하면 신뢰구간으로 최종 판정할 수 있습니다. 기록은 브라우저(localStorage)에만
저장되고 CSV로 내보내기/가져오기가 가능합니다.

## 사용법

### 웹앱 (권장)
1. 배포된 페이지를 열거나 `index.html`을 더블클릭합니다.
2. 당첨번호 CSV를 화면에 끌어다 놓습니다.
   - 표준 형식: `round, draw date, num1~num6`
   - 동행복권 내려받기 형식(CP949, 한글 헤더, 보너스 열 포함)도 자동 인식
3. 자동으로: 지난 예측 채점 → 누적 성과·판정 갱신 → 다음 회차 5세트 사전 등록
4. 매주 새 회차가 포함된 파일을 다시 놓기만 하면 됩니다.

### Python (Colab)
```python
# new_XXXX.csv 업로드 후
from lotto_integrated_v1_1 import quick_predict, full_analysis
quick_predict('/content/new_1235.csv')          # 예측 + 추적
full_analysis('/content/new_1235.csv')          # + 백테스트/최적화
```
Colab은 세션 종료 시 파일이 사라지므로 `prediction_log.csv`를 매번 내려받아
다음 세션에 함께 업로드하거나, Google Drive 마운트 경로를 `log_path`로 지정하세요.

## 검증 방법론 요약

- **누수 차단**: 백테스트의 매 라운드는 `history[:t]`만 학습에 사용
- **실측 대조군**: 이론값이 아닌, 같은 조건의 랜덤 표본과 직접 비교
- **부트스트랩 판정**: 시스템 평균이 랜덤 귀무분포 95% 구간의 안/밖인지로 결론
- **사전 등록**: 예측을 결과 공개 전에 기록 — 선택적 보고(체리피킹) 원천 차단

지금까지의 검증 결과, 이 엔진을 포함한 예측 시스템들은 랜덤과 **통계적 동률**
범위에 있습니다. 그것이 정상이며, 이 도구가 가르치려는 내용입니다.
